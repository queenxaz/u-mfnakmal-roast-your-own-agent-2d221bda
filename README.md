A roast of my own agent: thorough, confident, and completely beside the point.

## The entry

**My agent read 40 docs, ran 13 checks, and still submitted a haiku about printers. I asked for a genius; I got a very confident intern.**

## How it works

`main.py` writes the entry text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no
arguments: the entry is fixed, so every run produces the same bytes.
